# Projekty stron

Propozycje stron dla firm, publikowane przez GitHub Pages. Każda firma ma własny folder,
a link do pokazania to `https://<login>.github.io/<repo>/<folder>/`.

| Folder | Firma |
|---|---|
| `apollo-limanowa/` | Pizzeria Apollo, Rynek 19, Limanowa |
| `caverna-limanowa/` | Caverna Pizza & Pub, ul. Kościuszki 9, Limanowa |
| `jubiler-zaremba/` | Jubiler Maciej Zaremba, Rynek 3A i ul. Krakowska 5, Limanowa |
| `kancelaria-jedrzejek/` | Kancelaria Radcy Prawnego Krzysztof Jędrzejek, ul. M. B. Bolesnej 11A, Limanowa |
| `prodent-limanowa/` | Gabinet Stomatologiczny Prodent, lek. stom. Barbara Kunicka, ul. Ogrodowa 4, Limanowa |

Nowa firma: nowy folder ze statyczną stroną (`index.html` w środku), commit, push. Strony demo mają
`noindex`, żeby nie konkurowały w Google z prawdziwymi stronami firm.
